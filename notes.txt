Run DB locally:
docker run -d --name mariadb \
    -e MYSQL_ROOT_PASSWORD=root_password \
    -p 3306:3306 \
    -v mariadb_data:/var/lib/mysql \
    mariadb

Database via Entity Framework (ef):
- dotnet ef database drop (delete whole database)
- dotnet ef migrations add InitialCreate/[MIGRATION]
- dotnet ef database update (applies migrations)
- dotnet ef migrations remove (remove latest migration)
- dotnet ef database update PreviousMigrationName (rolling back to specific migration, use with causion)

Always check migration files for any wrongdoings
